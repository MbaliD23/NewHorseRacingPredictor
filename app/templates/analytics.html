Quick Guide

What these variables mean

Draw Advantage

The draw is the stall number. Some races suit inside draws, so this helps show whether a horse starts from a more helpful position.

Weight

This is the weight the horse carries in the race. Lower carried weight can make the job a little easier, especially in tight finishes.

Previous Run

This looks at how the horse finished last time. A lower finishing position usually means the horse came into this race in better recent form.

Trainer/Jockey Combination Win %

This shows how often this trainer and jockey win when they team up. Higher numbers suggest the partnership has worked well before.

Speed Index

This is a quick performance rating from the source site. Higher values usually point to stronger recent speed.

Predicted Time

This is the source site’s expected finishing time. Lower times are generally better because they suggest a faster run.

Good beginner combinations

Speed Index + Predicted Time

Performance-focused. Useful when you want to compare which horses look naturally quickest.

Weight + Draw Advantage

Race-condition-focused. Helpful when you want to see how the setup of the race might help or hurt a horse.

Trainer/Jockey Combination + Previous Run

Form-focused. Good for checking whether a horse comes in with both recent form and a proven rider-team partnership.
